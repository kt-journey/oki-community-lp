# デザインシステム: Okey-Dokey LP

## 1. デザインコンセプト
- ベンチマーク: 海士町オフィシャルアンバサダー（amb.amanowa.jp）の構造・UI設計を取り込みつつ、隠岐の島町独自のトーンへ差別化
- テーマ: **Oki Deep Forest & Ocean（隠岐の島町の豊かな杉林と深海を結ぶディープティールエメラルド）**
- 海士町との違い・差別化ポイント:
  - 海士町の色相（明るいシアンブルー `#0e6496`）から、**隠岐の島町ならではの深い森と海のティールエメラルド（`#0b332c` 〜 `#0d4a46` / `hue-rotate-45 saturate-125`）**へ変換
  - ボタン・アクセントも水色ではなく **落ち着きと生命感のある隠岐ティール（`#0f766e` / `#14b8a6`）**を採用

## 2. カラーパレット
- **Base Background**: `#0b332c`（隠岐の杉林と深い海を象徴するディープフォレストグリーン）
- **Gradient Overlay**: `from-[#0b332c]/80 via-[#0d4a46]/70 to-[#072420]/85`（多面体水面アニメーションの上に重なる落ち着いた深緑〜青緑グラデーション）
- **Text & Border**: `#FFFFFF`（純白）
- **Card Accent & Button Text**: `#0f766e`（ディープティール）
- **Glassmorphism**: `rgba(255, 255, 255, 0.16)` ＋ `backdrop-filter: blur(10px)` ＋ `border: 3px solid rgba(255, 255, 255, 0.85)`（rounded-3xl）

## 3. タイポグラフィ
- **和文**: `Zen Kaku Gothic New`（洗練され、角の取れたモダンな角ゴシック体）
- **欧文・数字**: `Plus Jakarta Sans`（シャープで洗練されたジオメトリック・サンセリフ）

## 4. コンポーネント指針
- **入会方法（Membership Process）**:
  - 実導線：**LP → 公式LINE → 入会フォーム・Stripe決済 → LINEオープンチャットへ招待**
  - 1枚の大きな白枠すりガラスボード内に `STEP 1〜3` を並べ、各ステップのスマホ画面モック（LINE友だち追加、月500円Stripe決済、オプチャ画面）を視覚化
- **３箇条（3 Rules）**:
  - 白枠すりガラスボードを白線で3分割し、丸数字バッジ（`①` `②` `③`）で提示
- **CTAボタン**:
  - 白塗り背景 ＋ ディープティール文字（`#0f766e`）＋ 白ボーダー
