# デザインシステム: Okey-Dokey LP

## 1. デザインコンセプト
- ベンチマーク: **海士町オフィシャルアンバサダー（amb.amanowa.jp）**
- テーマ: **Oki Ocean Blue & Frost Glass（透明感ある海の揺らめきとグラスモーフィズム）**
- トーン＆マナー:
  - 画面全体に「固定された海の水面ループ動画」を敷き、その上を白枠のすりガラス（グラスモーフィズム）カードが滑る構造
  - 「ディープオーシャンブルー × 純白（#FFFFFF）」の2色主義による圧倒的な清潔感と透明感
  - 「３箇条」および「入会方法（STEP ① ② ③）」による明快な視覚的オンボーディング

## 2. カラーパレット
- **Base Background**: `#0e6496`（日本海の深海ブルー）
- **Overlay Tint**: `rgba(26, 123, 106, 0.2)` ＋ `backdrop-brightness(1.25)`（エメラルドグリーンの光彩）
- **Primary Text & Border**: `#FFFFFF`（純白）
- **Card Accent Text**: `#0082c4`（マリンブルー / 白カード内・ボタン用）
- **Glassmorphism**: `rgba(255, 255, 255, 0.2)` ＋ `backdrop-filter: blur(8px)` ＋ `border: 4px solid #ffffff`（rounded-3xl）

## 3. タイポグラフィ
- **和文**: `Zen Kaku Gothic New`（誠実で柔らかく、現代的な角ゴシック体）
- **欧文・数字**: `Plus Jakarta Sans`（シャープで洗練されたジオメトリック・サンセリフ）

## 4. コンポーネント指針
- **入会方法（Membership Steps）**:
  - 1枚の大きな白枠すりガラスボード内に `STEP ①` `STEP ②` `STEP ③` を横並び（スマホは縦積み）で配置
  - 各ステップに白いスマホ画面モックアップ風グラフィック（QR、トーク画面、本登録）を配し、直感的にフローを理解させる
- **３箇条（3 Rules）**:
  - 1枚の白枠ボードを白線で3分割し、大きな丸数字バッジ（`①` `②` `③`）で「関わり方は自由」「フラットに」「月500円で安心を守る」を提示
- **CTAボタン**:
  - 白塗り背景 ＋ ブルー文字（`#0082c4`）＋ 4pxの白ボーダー（ホバー時は反転透過）
