# 要件定義書: Okey-Dokey LP

## 1. プロジェクト概要
- プロジェクト名: Okey-Dokey（隠岐の島町 UIターン者コミュニティ）
- 目的: 隠岐の島町における移住者（Iターン・Uターン）の孤立を防ぎ、定着率50%の壁を突破する「第3の居場所（ヨコのつながり）」を構築する
- ターゲット: 隠岐の島町に暮らす **20〜50代のIターン・Uターン者**
- 会費: **月額 500円（税込）** の有料メンバーシップ
  - ※コーヒー1杯分の会費を共有することで、冷やかしや勧誘のない安心・安全な場の質と持続可能な運営を守る
- **参加・入会導線（ファネル設計）**:
  1. **LP**（本サイト）: 課題・理念・3箇条・活動風景・会費の理由を理解
  2. **公式LINE**: 先行案内・立ち上げ情報・質問受付（完全無料）
  3. **コミュニティ入会フォーム ＆ Stripe決済**: 月額500円（税込）の安全なオンライン決済
  4. **限定LINEオープンチャットへご招待**: ニックネームで参加し、日常の交流・情報交換・イベント企画がスタート

## 2. ページ構成（全10セクション）
1. **Header**: ロゴ ＋ LINE先行登録ボタン
2. **Section 00: Hero**: 理念コピー ＋ CTA ＋ SCROLLインジケータ
3. **Section 01: はじめに**: 写真 ＋ 「小さな離島からはじまる、新しいヨコのつながり」
4. **Section 02: 背景にあること**: 3年以内離島率50%とヨコのつながりの重要性（白カードの数値強調）
5. **Section 03: 私たちの流儀**: 「都会のお金より、島の信頼でつながる」
6. **Section 04: 活動の風景**: 海・BBQ・送迎・空き家相談の4つの写真カード
7. **Section 05: ３箇条**: 白枠ボードで提示するメンバーの心構え（①関わり方は自由 ②フラットに ③月500円で安心を守る）
8. **Section 06: プランと会費**: 月額500円の理由（冷やかし防止・負担分散）
9. **Section 07: 入会方法**: LP → 公式LINE → 入会フォーム・Stripe決済 → LINEオープンチャット（スマホ画面モック付き）
10. **Section 08: よくある質問**: Uターン参加、40〜50代参加、オプチャの匿名性、いつでも解約可能などのFAQ
11. **Section 09: 最後に**: 集合写真 ＋ 「最初の100人と、隠岐の新しい日常をつくる」 ＋ CTA
12. **Footer**: 法的リンク3種（プライバシーポリシー・特商法・運営者情報） ＋ コピーライト
