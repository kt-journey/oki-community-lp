# 要件定義書: Okey-Dokey LP

## 1. プロジェクト概要
- プロジェクト名: Okey-Dokey（隠岐の島町 UIターン者コミュニティ）
- 目的: 隠岐の島町における移住者（Iターン・Uターン）の孤立を防ぎ、定着率50%の壁を突破する「第3の居場所（ヨコのつながり）」を構築する
- ターゲット: 隠岐の島町に暮らす **20〜50代のIターン・Uターン者**
- ビジネスモデル（会費）: **月額 500円（税込）** の有料メンバーシップ
  - ※プレローンチ期間中の「公式LINE先行登録」および「作戦会議（立ち上げ準備）」への参加は無料
  - ※コーヒー1杯分の会費を共有することで、冷やかしや勧誘のない安心・安全な場の質と持続可能な運営を守る
- LPのゴール（Phase A: プレローンチ）: 公式LINEへの先行登録（ウェイトリスト獲得）
- LPのゴール（Phase B: 正式ローンチ後）: 月額500円メンバーシップへの参加申込

## 2. フェーズ戦略
- **Phase A（プレローンチ / `waitlist`）**:
  - 主CTA: 公式LINEで先行案内を受け取る（無料）
  - コピー方針: 課題への共感、月額500円で守る安心な場の価値、初期メンバー100名での共創プロセスの提示
- **Phase B（正式ローンチ / `apply`）**:
  - 主CTA: メンバーシップに申し込む（月額500円）
  - コピー方針: 具体的な活動内容、参加メリット、即時のコミュニティ参加導線
- **共通方針**:
  - [content/site.ts](file:///Users/kota/Documents/Projects/Devlopment/oki-community-web-before/content/site.ts) で全セクションの文言を一元管理し、`NEXT_PUBLIC_SITE_PHASE` で切り替え可能にする

## 3. ページ構成（全7セクション・情報設計）
- **Section 00: Hero（表紙・巻頭）**
  - ターゲット明示: 「隠岐の島町｜20〜50代のIターン・Uターン者対象」
  - メインコピー: 「隠岐の暮らしを、もっと楽しく、もっと気楽に。」
  - ステータス表組み: 正式オープン後の会費（月額500円）と現在の先行登録（LINE無料）を誠実に明示
- **Section 01: The Issue（なぜこの場所をつくるのか）**
  - 年間約450人の転入に対し、3年以内の定着率が約50%にとどまる現実（独自調査）
  - 原因は仕事や住まいではなく「職場と家のあいだに、気兼ねなく話せるヨコのつながりがないこと」
  - 暗い背景で煽るのではなく、明るいミント背景のインフォグラフィックで前向きに提示
- **Section 02: Philosophy（私たちの流儀）**
  - 「都会の『お金』より、島の『信頼』でつながる。」
  - IターンもUターンも、年齢や職場の肩書きを外してフラットに混ざり合うサードプレイス
- **Section 03: For Whom（こんな方のために）**
  - 01: 職場や地域以外に、フラットな仲間が欲しい
  - 02: せっかくの島の自然を、誰かと遊びたい
  - 03: 島のリアルな暮らしの知恵を交換したい
- **Section 04: Activities（体験と仕組み・4つの風景）**
  - `Fig. 01` 海と船の体験（魚突き・漁船体験）
  - `Fig. 02` 週末の食卓と焚き火（BBQ・キャンプ）
  - `Fig. 03` 帰り道の助け合い（送迎・相乗り相談）
  - `Fig. 04` 住まいと暮らしの知恵袋（空き家・生活相談）
- **Section 05: Membership & Roadmap（月額500円の理由と参加の流れ）**
  - 正式オープン後の会費：月額500円（税込）※LINE先行登録は無料
  - 有料にする2つの理由：①安心・安全な場の質を守るため、②誰かひとりに負担を偏らせず長続きさせるため
  - オープンまでの3ステップ（LINE先行登録 → 作戦会議・プレ企画 → 正式オープン優先案内）
- **Section 06: FAQ（よくある質問）**
  - Uターンでも参加できるか、40〜50代や家族連れでも馴染めるか、見るだけの参加でもよいか、会費の発生タイミングについて回答
- **Section 07: Epilogue / Footer CTA（巻末案内）**
  - 「最初の100人と、隠岐の新しい日常をつくる。」
  - 公式LINEへの参加導線と法的ページ（プライバシーポリシー・特定商取引法表記・運営者情報）へのリンク
